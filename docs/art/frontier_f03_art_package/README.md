# Frontier F03 Art Continuity Package

This folder contains the canonical starting references for Frontier's city and first district visuals.

## Files

- `ART_DIRECTION.md` — overall rendering/style rules.
- `CITY_LAYOUT.md` — canonical city geography and landmark relationships.
- `CITY_MASTER_REFERENCE.png` — main visual reference.
- `HARBOR_REFERENCE.png` — Harbor visual reference.
- `INDUSTRIAL_REFERENCE.png` — Industrial visual reference.
- `continuity/HARBOR.md` — Harbor continuity rules.
- `continuity/INDUSTRIAL.md` — Industrial continuity rules.

## Important

These images are reference material only. Their baked text and labels must never be embedded in
the production game. Use clean, text-free production assets from `src/assets/locations/` with real
HTML/SVG labels and controls. Written art direction and geographic continuity remain authoritative.

The reference images are **directional**, while the Markdown files are the continuity source of truth.

If an image conflicts with a written continuity rule, the written continuity rule wins until a new visual reference is explicitly approved.

Do not regenerate production location artwork from scratch after approval. Future variants should be edits or reference-based derivatives of the approved canonical image.
